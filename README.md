Supply Tablet

This is a small Barotrauma content package that adds a handheld Supply Tablet item.
The in-game logistics terminal uses LuaCs / Lua For Barotrauma.

Install:
1. Copy the SupplyTablet folder into Barotrauma/LocalMods.
2. Install and enable LuaCs / Lua For Barotrauma if you want the real tablet UI.
3. Launch Barotrauma.
4. Enable "Supply Tablet" in the mods menu.
5. Start a round or open the submarine editor and spawn the item with identifier supplytablet.

The tablet is sold by common outpost merchants.
When LuaCs is active, holding or selecting the tablet opens a supply terminal with:
- boot/status screen
- real Barotrauma item catalog search
- category and merchant filters
- crew hire requests
- editable purchase manifest
- bought/open tracking
- budget and category reports

This mod is a planning/checklist tablet. It does not spend marks, buy cargo or hire crew automatically.
The manifest is saved locally into supply_tablet_data.lua next to the mod folder.
